# Physics Lab 3D｜雙語物理實驗室

Physics Lab 3D 是一個以瀏覽器為載體的 3D 物理教學模擬器。它把「斜坡上的球」做成可調參數、可重置、可量測的實驗：使用者可以改變質量、斜坡角度與摩擦係數，觀察球體的位移、速度、加速度、合力、法向力與摩擦力，並以中文或 English 閱讀同一套教學邊註。

目前版本聚焦於「運動與力」的第一個實驗切片，架構已為拋體、碰撞、彈簧與波動等後續實驗保留 `ExperimentDefinition`、固定時間步長與快照資料流。物理運算以獨立的 TypeScript 類別完成，React 只負責介面畫框，Babylon.js 負責 3D 舞台與向量呈現。

## 目前功能

| 模組 | 已實作內容 |
| --- | --- |
| 3D 實驗舞台 | 程序化斜坡、鋼球、支架、石墨理論板、透明材質、日光場景與可旋轉相機 |
| 物理模型 | 固定 1/120 秒步長、重力沿斜面分量、摩擦、合力、速度與加速度 |
| 即時量測 | 時間、位移、速度、加速度、法向力、摩擦力與完成狀態 |
| 雙語介面 | 中文 / English 切換，實驗索引、參數、教學邊註與操作提示保持語意對等 |
| 操作方式 | Play / Pause、Reset、質量 / 角度 / 摩擦係數滑桿、滑鼠旋轉相機與滾輪縮放 |
| 驗證模式 | `/?demo` 以 deterministic demo 自動播放一次可見的下滑實驗，方便截圖與回歸檢查 |

## 快速開始

```bash
pnpm install
pnpm dev
```

開發伺服器啟動後，瀏覽器開啟 Vite 顯示的本機網址。若要直接查看自動展示畫面，使用 `/?demo`。型別檢查與生產建置指令如下：

```bash
pnpm check
pnpm build
```

## 專案結構

```text
client/src/
  components/
    GameCanvas.tsx        # Babylon Engine 的 React 生命周期橋接
    LabShell.tsx          # 雙語畫框、索引、量測欄、教學邊註與控制列
  game/
    PhysicsWorld.ts       # 固定步長物理模型
    experiments.ts        # 實驗定義、雙語字串與參數型別
    scene.ts              # 相機、燈光、程序化器材、向量與軌跡
  App.tsx
  index.css

PLAN.md                   # 風險切片與驗收標準
STRUCTURE.md              # 架構與資料流
ASSETS.md                 # 生成資產與 WebDev URL
MEMORY.md                 # 開發決策與驗證紀錄
```

## 設計語言

遊戲採用 **Neo-Scientific Editorial / 天窗物理劇場**。暖白研究室、石墨理論板與天窗鈷藍 `#185ADB` 共同建立可讀的實驗氣氛；鈷藍代表觀察線與主要操作，琥珀橙代表能量與警示，薄荷綠代表穩定或完成。介面採左側研究索引、中央 3D 實驗舞台、右側量測註解的非對稱結構，並把向量、軌跡、角度與公式直接放回場景。

## 後續路線

下一個可獨立加入的切片是拋體運動：沿用同一套固定步長、快照與雙語教學介面，把斜面測量線替換為水平 / 垂直分量、拋物線軌跡與落點誤差。之後再加入可比較兩次試驗的量測記錄，讓使用者能把「調整參數」提升為「提出假設、測量、重做、比較」。
